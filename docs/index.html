Trid

Trid (Tri + 3D) is a small wireframe 3D renderer for the HTML <canvas>. It uses only the 2D context — no WebGL, no dependencies, no build step.

import { Scene } from "./trid/scene.js";
import { makeShape } from "./trid/render/shapes.js";
import { OrbitCamera, DragObject, HoverHighlight } from "./trid/tools/index.js";

const scene = new Scene(document.getElementById("demo-hero"), {
  width: 800, height: 400, camera: { z: -2 },
});

const ball = scene.add({
  mesh: makeShape("sphere", { r: 0.45, rings: 10, segments: 16 }),
  pos: { x: -0.6, y: 0, z: 0 },
  color: "#E9806E",
});
const box = scene.add({
  mesh: makeShape("cube", { size: 0.6 }),
  pos: { x: 0.6, y: 0, z: 0 },
  color: "#7ae96e",
});

scene.use(new OrbitCamera());
scene.use(new DragObject());
scene.use(new HoverHighlight());

scene.start((dt) => {
  ball.rot.y += dt * 0.6;
  box.rot.x += dt * 0.8;
  box.rot.y += dt * 0.5;
});

What it does

  • Scene — holds a canvas, a camera and your objects, and runs the frame loop for you.
  • Shapes — cubes, boxes and spheres out of the box, or any mesh you define as vertices and edges.
  • Camera — position, yaw, pitch, field of view, with near-plane clipping so nothing behind the camera is drawn.
  • Tools — ready-made orbit and fly cameras, object dragging, hover highlighting and an FPS meter. Writing your own is a plain object with a few methods.
  • Pure math — every transform and projection function is exported, so you can use the pipeline piece by piece.

Quick start

Trid is a folder of ES modules. Copy the trid/ folder next to your page:

my-project/
├── index.html
├── main.js
└── trid/
    ├── scene.js
    ├── math/
    ├── render/
    └── tools/

Add a canvas and load your script as a module:

<!DOCTYPE html>
<html lang="en">
<body>
  <canvas id="canvas"></canvas>
  <script type="module" src="main.js"></script>
</body>
</html>

Then create a scene, add a shape and start the loop:

import { Scene } from "./trid/scene.js";
import { makeShape } from "./trid/render/shapes.js";

const scene = new Scene(document.getElementById("demo-quick"), {
  width: 800, height: 300,
});

const cube = scene.add({ mesh: makeShape("cube"), color: "#E9806E" });

scene.start((dt) => {
  cube.rot.x += dt;
  cube.rot.y += dt * 0.7;
});

Use a local server. Browsers block ES module imports from file:// pages. From your project folder run python3 -m http.server (or npx serve) and open http://localhost:8000.

Current limits

  • Wireframes only — there are no filled faces, lighting or depth sorting yet.
  • Picking (used by dragging and hover) tests each object's screen-space bounding box, so clicking near a sphere's corner still picks it.
  • There is no single entry file or npm package yet: import from the individual modules.
