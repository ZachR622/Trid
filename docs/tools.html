Tools

Tools add interaction and overlays to a scene: camera controls, dragging, hover effects, an FPS counter. Add one with scene.use(tool).

import {
  OrbitCamera, FlyCamera, DragObject, HoverHighlight, FpsMeter,
} from "./trid/tools/index.js";

scene.use(new OrbitCamera());      // camera tools first
scene.use(new DragObject());       // object tools after, so they get clicks first
scene.use(new HoverHighlight());
scene.use(new FpsMeter());

How tools share the mouse

The scene owns the canvas's mouse, touch and scroll listeners and passes events on to its tools. Tools are stacked like layers:

  • The last tool added gets the first chance at a click or a scroll.
  • The first tool that accepts a click gets the whole drag, until the button is released.
  • While nothing is being dragged, every tool sees pointer moves (for hover effects).

That's why the order above works: clicking an object starts a DragObject drag, and clicking empty space falls through to OrbitCamera.

Use one camera tool at a time. Two tools moving the same camera will fight over it.

OrbitCamera

Turns the camera around a target point. It starts from wherever the camera currently is.

InputAction
Left dragOrbit around the target
Right drag, middle drag, or Shift + left dragPan (moves the target with the cursor)
ScrollZoom in and out
OptionDefaultMeaning
target{ x: 0, y: 0, z: 0 }Point to orbit around
distancecamera's distance to targetStarting distance
yaw, pitchcamera's yaw / pitchStarting angles
rotateSpeed0.005Radians per dragged pixel
zoomSpeed0.001Zoom amount per scroll unit
minDistance0.1Closest zoom
maxDistance100Farthest zoom
rotate, pan, zoomtrueTurn each control off with false

target, distance, yaw and pitch are public properties you can change at any time. Pitch is kept just under ±90° so the view never flips.

OrbitCamera places the camera every frame. To move the view in code, change the tool's properties (e.g. orbit.yaw += dt), not scene.camera — direct camera changes are overwritten.

import { Scene } from "./trid/scene.js";
import { makeShape } from "./trid/render/shapes.js";
import { OrbitCamera } from "./trid/tools/index.js";

const scene = new Scene(document.getElementById("demo-orbit"), {
  width: 800, height: 320, lineWidth: 2, camera: { z: -2 },
});
scene.add({ mesh: makeShape("sphere", { r: 0.5 }), color: "#8ab4f8" });

const orbit = scene.use(new OrbitCamera({ pitch: -0.3, minDistance: 0.8, maxDistance: 5 }));

let idle = 0;
scene.canvas.addEventListener("pointerdown", () => (idle = 0));
scene.start((dt) => {
  idle += dt;
  if (idle > 2) orbit.yaw += dt * 0.3;   // spin slowly when nobody touches it
});

FlyCamera

A free-flying camera driven by the keyboard and mouse.

InputAction
W / SForward / back
A / DLeft / right
E / QUp / down
Arrow keysTurn
Left dragLook around
Hold ShiftMove faster

Keys use physical positions (KeyboardEvent.code), so on an AZERTY keyboard the same keys are Z Q S D. Keys are ignored while typing in an input.

OptionDefaultMeaning
speed1Units per second
fastMultiplier3Speed multiplier while Shift is held
turnSpeed1.5Radians per second with the arrow keys
lookSpeed0.005Radians per dragged pixel

FlyCamera listens to the keyboard on the whole window and stops the arrow keys from scrolling the page. On a page with other content, add it only while the canvas is in use — the demo below does exactly that.

import { Scene } from "./trid/scene.js";
import { makeShape } from "./trid/render/shapes.js";
import { FlyCamera } from "./trid/tools/index.js";

const canvas = document.getElementById("demo-fly");
const scene = new Scene(canvas, {
  width: 800, height: 320, lineWidth: 2, camera: { y: 0.3, z: -3 },
});

// A field of cubes to fly through
const cube = makeShape("cube", { size: 0.3 });
for (let x = -3; x <= 3; x++) {
  for (let z = 0; z <= 6; z++) {
    scene.add({ mesh: cube, pos: { x, y: 0, z }, color: `hsl(${(x + z) * 25}, 70%, 65%)` });
  }
}

// Only take the keyboard while the canvas is being used
const fly = new FlyCamera({ speed: 2 });
canvas.addEventListener("pointerdown", () => scene.use(fly));
document.addEventListener("pointerdown", (e) => {
  if (e.target !== canvas) scene.unuse(fly);
});

scene.start();

DragObject

Click an object to pick it, then drag to move it. The object follows the cursor exactly, parallel to the screen. Hold Shift while dragging to push it away (drag up) or pull it closer (drag down).

OptionDefaultMeaning
button0Mouse button that drags (0 left, 1 middle, 2 right)
filterobjects without draggable: false(obj) => boolean: which objects can be dragged
onPick—(obj) => void: called when an object is picked
onMove—(obj) => void: called each time it moves
onDrop—(obj) => void: called when it's released

tool.dragging is the object being dragged, or null. Objects are found with pick, which uses screen-space bounding boxes.

HoverHighlight

Recolors the object under the pointer, and puts its own color back when the pointer leaves it, leaves the canvas, or the tool is removed.

OptionDefaultMeaning
color"#ffffff"Highlight color
filterobjects without hoverable: false(obj) => boolean: which objects can be highlighted
onChange—(obj | null) => void: called when the hovered object changes

tool.hovered is the object under the pointer, or null.

FpsMeter

Draws the frames per second in a corner of the canvas. The value is averaged and refreshed every interval seconds so it stays readable.

OptionDefaultMeaning
color"#ffffff"Text color
font"14px monospace"CSS font
corner"top-left""top-left", "top-right", "bottom-left" or "bottom-right"
interval0.5Seconds between refreshes

tool.fps holds the last reading. It only counts while the scene is running.

All together

import { Scene } from "./trid/scene.js";
import { makeShape } from "./trid/render/shapes.js";
import { OrbitCamera, DragObject, HoverHighlight, FpsMeter } from "./trid/tools/index.js";

const scene = new Scene(document.getElementById("demo-tools"), {
  width: 800, height: 360, lineWidth: 2, camera: { y: 0.6, z: -2.5 },
});

for (let i = 0; i < 5; i++) {
  scene.add({
    mesh: makeShape(i % 2 ? "cube" : "sphere", { size: 0.35, r: 0.2, rings: 6, segments: 10 }),
    pos: { x: (i - 2) * 0.55, y: 0, z: 0 },
    color: `hsl(${i * 60 + 10}, 75%, 65%)`,
  });
}
// A floor that can't be dragged or highlighted
scene.add({
  mesh: makeShape("box", { w: 3, h: 0.01, d: 1.5 }),
  pos: { x: 0, y: -0.3, z: 0 },
  color: "#444", draggable: false, hoverable: false,
});

scene.use(new OrbitCamera());
scene.use(new HoverHighlight());
// Lift a shape slightly while it's held
scene.use(new DragObject({
  onPick: (obj) => (obj.lineWidth = 4),
  onDrop: (obj) => delete obj.lineWidth,
}));
scene.use(new FpsMeter({ color: "#888", corner: "top-right" }));
scene.start();
