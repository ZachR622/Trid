Writing a tool

A tool is any object with some of a few optional methods. There's no base class to extend — a plain object works, and so does a class.

The smallest tool

// Draws a crosshair in the middle of the canvas
scene.use({
  draw(ctx, scene) {
    const { width, height } = scene.canvas;
    ctx.strokeStyle = "#888";
    ctx.lineWidth = 1;
    ctx.beginPath();
    ctx.moveTo(width / 2 - 8, height / 2);
    ctx.lineTo(width / 2 + 8, height / 2);
    ctx.moveTo(width / 2, height / 2 - 8);
    ctx.lineTo(width / 2, height / 2 + 8);
    ctx.stroke();
  },
});

The tool interface

Every method is optional. Each one receives the scene as its last argument.

MethodWhen it's called
attach(scene)When the tool is added with scene.use
detach(scene)When it's removed with scene.unuse or scene.destroy. Remove your own listeners here.
pointerDown(e, scene)A button is pressed on the canvas. Return true to take the drag.
pointerMove(e, scene)The pointer moves. During a drag, only the tool holding it is called; otherwise every tool is (for hover effects).
pointerUp(e, scene)The drag this tool took is released
pointerLeave(scene)The pointer left the canvas (not called during a drag)
wheel(e, scene)Scroll over the canvas. Return true to use it (stops the page from scrolling).
update(dt, scene)Every frame, before your own update (only while scene.start is running)
draw(ctx, scene)Every render, after the objects are drawn

One property is also read:

  • blockContextMenu: true — disables the right-click menu on the canvas while the tool is added.

Who gets the click

pointerDown and wheel go to tools from the last added to the first. The first tool that returns true stops the search. If your tool returns false (or nothing), the click falls through to the tools below it.

Event objects

Pointer events

Received by pointerDown, pointerMove and pointerUp. Mouse, pen and touch all produce them.

FieldMeaning
x, yPointer position in canvas pixels, even if the canvas is scaled with CSS
dx, dyMovement since the last event, in canvas pixels (0 on pointerDown)
buttonButton that changed: 0 left, 1 middle, 2 right
shiftKey, ctrlKey, altKeyModifier keys
originalThe DOM PointerEvent

Wheel events

FieldMeaning
x, yPointer position in canvas pixels
deltaYScroll amount (> 0 scrolls down)
originalThe DOM WheelEvent

Example: click to select

This tool selects the clicked object and draws a dashed box around it. It returns false from pointerDown, so the click still reaches OrbitCamera below it and you can select and orbit in one gesture. The helpers pick and screenBounds do the hard part.

import { Scene } from "./trid/scene.js";
import { makeShape } from "./trid/render/shapes.js";
import { OrbitCamera, pick, screenBounds } from "./trid/tools/index.js";

class SelectTool {
  constructor({ color = "#ffd166", onSelect } = {}) {
    this.color = color;
    this.onSelect = onSelect;
    this.selected = null;
    this._onKey = this._onKey.bind(this);
  }

  attach(scene) {
    this.scene = scene;
    window.addEventListener("keydown", this._onKey);
  }

  detach() {
    window.removeEventListener("keydown", this._onKey);
    this.selected = null;
  }

  pointerDown(e, scene) {
    if (e.button !== 0) return false;
    this.selected = pick(scene, e.x, e.y);
    this.onSelect?.(this.selected);
    return false;   // let the camera tool below use the drag too
  }

  draw(ctx, scene) {
    if (!this.selected) return;
    const box = screenBounds(scene, this.selected);
    if (!box) return;
    const pad = 6;
    ctx.save();
    ctx.setLineDash([6, 4]);
    ctx.lineWidth = 1.5;
    ctx.strokeStyle = this.color;
    ctx.strokeRect(box.minX - pad, box.minY - pad,
                   box.maxX - box.minX + pad * 2, box.maxY - box.minY + pad * 2);
    ctx.restore();
  }

  _onKey(e) {
    if (e.key === "Delete" && this.selected) {
      this.scene.remove(this.selected);
      this.selected = null;
    }
  }
}

const scene = new Scene(document.getElementById("demo-select"), {
  width: 800, height: 320, lineWidth: 2, camera: { z: -2.2 },
});
["cube", "sphere", "box"].forEach((kind, i) => scene.add({
  mesh: makeShape(kind, { size: 0.4, r: 0.25, w: 0.5, h: 0.25, d: 0.3, rings: 8, segments: 12 }),
  pos: { x: (i - 1) * 0.7, y: 0, z: 0 },
  color: ["#E9806E", "#7ae96e", "#8ab4f8"][i],
}));

scene.use(new OrbitCamera());
scene.use(new SelectTool());   // added last, so it sees clicks first
scene.start();

Tips

  • Clean up in detach. Anything you add to window or document in attach should be removed there. The scene already handles canvas listeners for you.
  • Use dt in update so movement doesn't depend on frame rate.
  • Restore canvas state in draw with ctx.save() / ctx.restore() if you change things like line dashes or transforms.
  • Make following the cursor exact with worldPerPixel, plus cameraRight / cameraUp to turn pixel movement into world movement — that's how DragObject works.
  • Keyboard tools should ignore keys while the user types in an input (check e.target.tagName), like FlyCamera does.
